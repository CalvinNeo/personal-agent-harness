# QQ 图片上下文

在允许的群里发送一张或多张图片，然后 @机器人说：

- `帮我看看上一张图`
- `总结刚才三张图`
- `对比一下刚发的那几张图`

插件只记住 QQ 官方平台实际推送的顶层图片。QQ 若未推送普通群消息，需要发送图片时也 @机器人。引用、转发消息中的图片不会递归读取。

连续上传（相邻上传间隔不超过 2 分钟）的图片视为一批；“那几张图”选最近一批，“三张图”选最近三张。找不到或数量不足时，直接提示重发，不请求模型猜测。

只在 `allowed_umos` 授权的群启用，默认空列表拒绝所有群。可通过 `allowed_senders` 进一步限制发送者。缓存按完整群会话 UMO 和发送者分开，30 分钟有效，每人每群最多 12 张，总共最多 64 个发送者会话。只缓存 QQ 图片域名的 HTTPS URL，不下载、不写文件、不记录 URL；重启清空。被动收到图片只缓存，不额外回复。

后续提问必须 @机器人或使用既有唤醒方式。发送给普通模型的历史图片使用 AstrBot 临时消息组件，不加入持久化聊天历史。AstrBot 本身可能为模型准备临时图片文件，其处理行为由框架管理；此插件不改变原有群会话是否共享的配置。模型仍需支持图片。

验证：`python3 -m unittest discover -s plugins/image_context -p 'test_*.py' -v`。
