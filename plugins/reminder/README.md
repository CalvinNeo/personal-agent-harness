# AstrBot 本地提醒插件

该插件在 AstrBot 进程内解析、持久化和调度提醒；普通模型与 Codex 都调用同一执行器。已授权群聊和私聊均可使用，到期消息回到原会话。相对时间以原消息接收时间为基准，跨路径重试不会重复创建。

经桥接器验证的 Codex 调用不再根据当前消息关键词校验提醒意图，模型可用
`create_schedule_reminders` 提供完整的日程时间、内容和提前分钟数；取消使用本人当前会话的
提醒编号。普通消息继续使用原规则。时间完整性、过去时间、额外 @、配额和归属检查不变。
同一调用重试复用回执，不重复创建；同一任务里的不同日程批次可分别创建。
沿用线上 1.3.5 的配置语义：`max_delay_seconds` 未设置、0 或旧默认 604800 表示没有固定
未来日期上限；其他正值仍是管理员设置的时间范围限制。

## 部署

将本目录复制到服务器的 `/var/lib/astrbot/data/plugins/reminder/`，并创建 `/var/lib/astrbot/data/config/reminder_config.json`。`allowed_umos` 必须填已批准群的完整 UMO，例如：

```json
{
  "allowed_umos": ["private_qq_bot:GroupMessage:<群 OpenID>"],
  "allowed_senders": []
}
```

空的 `allowed_umos` 会拒绝所有请求。重启 `astrbot.service` 后插件会从 `reminders.json` 恢复未到期任务。提醒文件由插件原子写入并设置为 `0600`。

## 用法

在允许的 QQ 群里 @机器人，可以直接说：

```text
两分钟后提醒我喝水
请在半小时后提醒我开会
提醒我明天下午三点开会
明天早上八点叫我起床
两分钟后提醒我喝水，三分钟后提醒我吃药
明天下午三点提醒我开会，四点提醒我出门
```

时间统一按北京时间解释；含糊的“一会儿”、没有说明上午/下午的“三点”会要求补充。只支持自己的一次性提醒，提醒日期不设固定天数上限；仍会拒绝过去或过近的时间。一次消息可以创建多条提醒（最多受每群/每人数量上限约束）；所有条目会先完整校验，再一次性保存，任一条无效时不会创建部分任务。否定、引用、讨论提醒功能不会自动创建任务。以“已设置 N 条提醒”和具体时间的回复为准。普通聊天仍走原来的模型。

原有命令继续可用：

```text
/提醒 2分钟后提醒我喝水
/提醒 2分钟后喝水，3分钟后吃药
/提醒 2026-10-28 18:30 开会
/提醒列表
/提醒取消 <ID>
```

QQ 开放平台必须对目标群开启机器人主动发言/主动推送权限；用户关闭主动消息时，QQ 可能返回 `40034105`，插件会在 AstrBot 日志中记录失败。

审计：`journalctl -u astrbot.service --since '30 minutes ago' --no-pager`，查找 `Reminder created id=`、`Failed to send reminder`、`scheduler started`。持久化记录在 `reminders.json`；发送成功后删除。群白名单、发送者限制和每人/每群数量限制对自然语言和命令一致生效。
